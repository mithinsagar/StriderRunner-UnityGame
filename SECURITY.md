# Security Policy

Author: Mithin Sagar S
GitHub: https://github.com/mithinsagar

## Supported Versions

The most recent minor release on the `main` branch is supported.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security-relevant issue in Strider Runner (for example, a
save-file exploit, an issue in a bundled dependency, or a supply chain concern
with `Packages/manifest.json`), please do not open a public issue.

Instead, contact the maintainer through the GitHub profile at
https://github.com/mithinsagar with the subject line "Strider Runner security
report". Include a description of the issue, reproduction steps, and any
suggested mitigation.

You can expect an initial acknowledgement within seven days. Fixes for
confirmed issues will be released as patch versions and disclosed in the
`CHANGELOG.md` after users have had a reasonable window to update.
