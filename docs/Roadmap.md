# Roadmap

Author: Mithin Sagar S
GitHub: https://github.com/mithinsagar

Planned work, grouped by area. Items in the current release are listed in
`CHANGELOG.md`. Anything below is open for contribution.

## Input and UX

- Gamepad navigation for all UI screens.
- Runtime rebinding UI in Settings.
- Screen transition fade in and out.

## Player and Combat

- Player character with full combat support (combos, hit reactions).
- Parry window on the sword strike.
- Dash-cancel into attack.

## Enemies

- Flying enemy archetype.
- Charging enemy archetype.
- Mini-boss encounter for the final level.

## World

- Parallax background scrolling.
- Weather layer (rain, dust) as a scriptable modifier.
- Secret rooms with unlockable characters.

## Systems

- Move save layer from PlayerPrefs to a serialisable save file with versioning.
- Localisation using Unity Localization package.
- Telemetry-free crash breadcrumbs stored locally.

## Tooling

- Editor tool for placing checkpoints along a spline.
- Playtest recording that logs input and replays it.
